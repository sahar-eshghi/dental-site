# Blue Dental — GitHub Pages Ready

نسخه استاتیک HTML / CSS / JavaScript دندانپزشکی آبی، آماده برای GitHub Pages.

## ساختار
- `index.html` — صفحه اصلی و فایل ورودی GitHub Pages
- `about.html` — درباره ما
- `services.html` — خدمات
- `treatments.html` — تخصص‌ها
- `technology.html` — تکنولوژی
- `blog.html` — مجله
- `contact.html` — تماس
- `css/` — استایل‌ها
- `js/` — JavaScript
- `images/` — تصاویر محلی
- `.nojekyll` — جلوگیری از پردازش Jekyll برای سایت استاتیک

فرم رزرو نوبت در نسخه GitHub Pages حالت نمایشی دارد و برای ارسال واقعی باید به سرویس نوبت‌دهی، واتساپ، ایمیل یا بک‌اند متصل شود.
